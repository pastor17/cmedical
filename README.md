# 中医之道 · The Way of Chinese Medicine

> A plain-English, educational introduction to **Traditional Chinese Medicine (TCM)** — what it is, its history, its main practices, and how it’s used today alongside modern medicine.

This is the **`master`** branch of this repo. Built with [Hugo](https://gohugo.io) as a pure static site, deployed to **GitHub Pages** via GitHub Actions.

## Branches

- **`master`** (this branch) — the TCM introduction site (this repo’s main branch).
- **`medical`** — the [ChinaCare](https://github.com/pastor17/cmedical) medical portal, a separate Hugo site for international patients.

## What’s here

- **Practices** — the main TCM practices: acupuncture, herbal medicine, tuina, cupping, moxibustion, dietary therapy, qigong, and TCM diagnosis.
- **Core Ideas** — balance & harmony, qi, yin & yang, and pattern diagnosis.
- **About** — what this site is (and isn’t).

## Local development

```bash
hugo server -D     # dev server at http://localhost:1313/
hugo --minify      # production build into public/
```
